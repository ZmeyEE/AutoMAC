AutoMAC Linux 組員包（內含 token，只給實驗室成員，不要上傳或轉貼）

這一包是沒有視窗的背景服務版：裝好後開機自動執行，偵測被限速時自動換 MAC，沒有右下角圖示。
想看狀態用指令（下面有）；要用視窗請用 Windows 版。

需求
- 有 systemd 的 Linux（Debian、Ubuntu、Raspberry Pi OS、Fedora）、Python 3.11 以上。
- 安裝時需要連網（pip 會下載 psutil 與 zeroconf，約 1 MB）。
- 只支援有線網卡；無線網卡不支援。
- ip 指令、python3、python3-venv 缺的話，安裝腳本會用 apt 或 dnf 自動補裝（會先告訴你裝了什麼）。

安裝（一鍵）
    tar -xzf AutoMAC-Linux.tar.gz && cd AutoMAC-Linux && ./install.sh
- 如果拿到的是 .rar（需要先安裝 unrar 或 7z）：解壓縮後進入 AutoMAC-Linux 資料夾，執行 bash install.sh。
  .rar 解壓縮後檔案沒有執行權限，所以不能直接 ./install.sh，用 bash 開就可以。
- 不是 root 會自動改用 sudo（可能要輸入你的密碼）。
- 腳本最後會確認服務真的在跑並顯示目前狀態。之後這個資料夾可以刪掉，不影響運作。
- 重複執行是安全的：程式與服務會更新，已有的設定不會被覆蓋。

安裝腳本做的事（都在 install.sh 裡，可以先讀）
- 程式放 /opt/automac；設定與 token 放 /var/lib/automac（只有 root 讀得到）；建立指令 /usr/local/bin/automac。
- 建立 systemd 服務 automac-client（開機啟動、失敗 10 秒後重啟、只保留換 MAC 需要的權限）。
- 第一次執行會自動加入實驗室伺服器並同步 MAC 清單，不需要輸入任何東西。

看狀態
- sudo automac live          目前網卡、MAC、IP、與伺服器同步狀況與最近事件
- sudo automac status        網卡與池內各 MAC 的狀態（會掃描區網，約 3 秒）
- journalctl -u automac-client -f    即時日誌
- sudo systemctl status automac-client

兩種情況（和 Windows 版相同）
- 這台電腦目前的 MAC 在清單內：預設只監看。要在被限速時自動換 MAC，執行 sudo automac auto on（關掉用 off，重開機後維持）。
- 目前的 MAC 不在清單內（沒申請的 MAC）：服務會自動向伺服器要一個沒人用的 MAC 並切換，網路會中斷數秒。

手動換 MAC
- sudo automac auto on|off         開關「被限速時自動切換」（等於 Windows 版視窗裡的勾選方塊）
- sudo automac switch              由伺服器挑一個沒人用的（背景服務在跑時，由服務去換，不會另起程序）
- sudo automac switch 00:00:5e:00:53:21    指定
- 換 MAC 只改目前運作中的網卡，不寫進設定：重開機後網卡回到硬體原本的 MAC，服務開機後會再自動入網。

移除
- sudo bash /opt/automac/uninstall.sh（停止服務、刪程式與本機設定；解壓縮的資料夾刪掉了也能用這個）。MAC 清單、標籤與用量都在伺服器上，不會遺失。

注意
- 換 MAC 時網路會中斷。若你是用 SSH 連到這台機器，連線會斷幾秒，之後自己會恢復（IP 可能變）。
- 取得 IP 靠系統既有的網路管理程式：NetworkManager、systemd-networkd、dhcpcd 會被通知重新取址；
  用 ifupdown 加 dhclient 的舊系統可能拿不到新位址，服務會在逾時後換回原 MAC，不會留下斷線狀態。
- 若 NetworkManager 的連線設定有指定 cloned-mac-address，它會在重新連線時蓋掉我們換的 MAC，請改成 preserve。
- 啟動失敗時看：journalctl -u automac-client -e
