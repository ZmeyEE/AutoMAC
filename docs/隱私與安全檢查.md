# 公開前的隱私與網路安全檢查

這份紀錄說明：公開這個專案之前，我們檢查了哪些地方會洩漏個人資料或造成網路安全問題、各自怎麼處理、哪些風險仍然存在。
做法是先複製一份專案，在副本上掃描與淨化，反覆掃描直到沒有命中才發布。紀錄裡**不含任何真實的位址、名稱或金鑰**。

## 一、檢查範圍

專案原始碼（`src/`）、測試（`tests/`）、開發工具（`tools/`）、Windows 部署腳本（`server/`）、Linux 部署腳本（`pi/`）、
研究紀錄（`research/`）、實測樣本（`samples/`）、流程圖與截圖（`docs/`）、Word 開發文件，以及這些檔案的內部結構
（Word 內部的 XML、文件屬性、內嵌圖片）。

## 二、發現的問題與處理

| 類別 | 發現 | 風險 | 處理 |
|---|---|---|---|
| 真實 MAC 位址 | 原始碼註解、測試資料、腳本、文件、截圖中出現實驗室登記的 MAC 與個人電腦的 MAC | 可被拿去冒用身分或追蹤裝置 | 全部換成保留給文件的 `00-00-5E-00-53-xx`（保留各 MAC 的最後一個位元組，使它們彼此仍不相同，測試邏輯不變） |
| 真實 IP 位址 | 實驗室網段的伺服器、閘道、電腦位址；另一個子網的位址 | 暴露內部網路結構與目標 | 換成 RFC 5737 文件保留段 `192.0.2.0/24`、`198.51.100.0/24` |
| 主機與裝置名稱 | 伺服器、電腦、樹莓派的真實電腦名稱與標籤 | 暴露實驗室內裝置與角色 | 換成 `LAB-SERVER`、`LAB-PC-01`、`pi-monitor` 等通用名稱 |
| 學校、實驗室與人名 | 註解與文件中的校名、實驗室名稱、系統使用者名稱 | 可識別個人與所屬單位 | 換成「學校」「實驗室」等通用詞；使用者名稱全部移除 |
| 開發用遠端登入 | 啟用／停用 SSH 的腳本、含伺服器位址與使用者名稱的遠端執行腳本、公鑰與已知主機紀錄的引用 | 暴露伺服器遠端入口與帳號 | **整組移除**（`enable-ssh`、`disable-ssh`、`srv.sh`），不進公開庫 |
| 實驗室專用測試腳本 | 會真的切換伺服器網卡的端對端腳本（含真實 MAC、固定路徑） | 公開後被誤用會讓伺服器斷線 | 移除（公開庫保留 `tools/switch_roundtrip.py` 這種需要自己帶參數的版本） |
| 本機絕對路徑 | 原始碼與腳本內的磁碟路徑、含使用者名稱的暫存路徑 | 暴露本機目錄結構與使用者名稱 | 改成相對路徑或通用說明；只和本機文件有關的合併腳本不收錄 |
| 截圖 | 兩張視窗截圖顯示真實 MAC、IP、電腦名稱、用量 | 同上 | 改用假資料重新產生（`tools/gui_demo_screenshot.py`）；圖說從「實機畫面」改為「示範資料畫面」；部署拓樸圖重新產生並拿掉位址片段 |
| Word 文件 | 內文含上述識別資訊；文件屬性的作者與最後修改者為真實姓名 | 同上 | 內文逐項淨化（含跨格式區段的識別字）、屬性改為 `AutoMAC contributors`、截圖替換 |
| 設定與機密 | `config.json`、`automac-client.json`、憑證與私鑰、`local.token`、用量與標籤檔 | 外洩 token 等於可冒充組員 | 從未放進公開庫；`.gitignore` 明確排除；掃描時以本機真實 token 與指紋比對，確認副本中沒有任何一筆 |
| 殘留的基礎設施細節 | 伺服器安裝路徑、共用資料夾名稱、其他服務名稱、舊腳本註解中的遠端連線說明 | 暴露實驗室環境與運作方式 | 路徑改成可用環境變數指定的通用預設值；共用資料夾名稱改成參數；其他服務名稱與遠端連線描述移除 |
| 檔案內的隱藏資訊 | 圖片內嵌的文字區塊（產生圖片的軟體與版本字串）、Word 的編輯工作階段識別碼 | 可用來關聯檔案與產生環境 | 所有 PNG 只保留繪圖必要的區塊；Word 移除編輯工作階段識別碼 |
| 程式：外掛命令 | `hooks_before` / `hooks_after` 以 shell 執行命令，且第一次執行時會從 `automac-client.json` 讀入所有欄位 | 別人遞來的設定檔可夾帶命令，等同遠端執行 | 新增 `allow_hooks`（預設 false，未開啟就略過並警告）；組員設定檔改為白名單，只收連線欄位；新增兩項測試 |
| Git 歷史 | 開發過程的所有版本 | 舊版本可能含已移除的資訊 | 公開庫從淨化後的副本重新建立，只有一個乾淨的提交，不帶任何歷史 |

## 三、掃描方法（重複多輪，直到零命中）

0. 範圍說明：「風險降到 0」指公開內容不含任何個人資料、真實位址、金鑰與可利用的基礎設施細節。軟體本身無法保證零漏洞，所以程式層改成預設安全，剩下的限制誠實列在最後一節。
1. 檔案內容：IPv4、MAC（帶分隔與連續 12 碼）、電子郵件、長十六進位字串（金鑰與指紋）、私鑰與憑證區塊、
   含 token／密碼的賦值、使用者目錄與磁碟路徑、SSH 金鑰相關字眼。
2. 指名比對：把本機真實的 token、憑證指紋、所有登記 MAC，以及已知的主機名稱、校名、帳號名稱，逐一搜尋副本中的每個檔案。
3. Word 內部：解開檔案後掃描所有 XML（含文件屬性），並逐一檢視內嵌圖片。
4. 圖片：人工逐張檢視（掃描程式無法讀圖中的文字）。
5. 淨化後重新執行全部測試，確認替換沒有破壞程式行為（修正了兩個測試輸入）。

## 四、網路安全審查（程式本身）

| 項目 | 現況 | 評估 |
|---|---|---|
| 傳輸加密 | 僅 TLS 1.3；明文與舊版 TLS 連線被拒 | 良好 |
| 伺服器身分 | 憑證釘選，握手後先比對指紋才送資料 | 良好；憑證無撤銷機制 |
| 驗證 | 256 位元 token、常數時間比對、失敗鎖定、請求大小上限、握手逾時 | 良好；全實驗室共用單一 token |
| 本機控制介面 | 只綁 127.0.0.1、token 檔限管理員、Host 標頭檢查 | 良好 |
| 外掛命令 | `hooks_*` 預設不執行（`allow_hooks=false`）；組員設定檔只收白名單欄位 | 良好；自己開啟 `allow_hooks` 後設定檔等同可執行程式，文件已警告 |
| 伺服器監聽位址 | 預設監聽所有網卡 | 由防火牆限制在本機子網：`server/open-firewall.ps1` 提供，`SECURITY.md` 已註明（沒有這兩條規則請不要啟用伺服器角色） |
| 區網揭露 | mDNS 廣播目前 MAC、IP、電腦名稱 | **風險**：隱私外洩給同網段；可用 `use_presence=false` 關閉 |
| 子程序 | PowerShell 以 `-EncodedCommand`、所有外部輸入經 `ps_quote` 跳脫；其餘用參數陣列不經 shell | 良好 |
| 自刪資料夾 | 解除安裝時由獨立 cmd 刪除，且只在資料夾確實是 ProgramData 底下的 AutoMAC 時才整個刪 | 良好（有測試） |
| 單檔 exe | PyInstaller 打包、未簽章 | 可能被防毒誤報；沒有自動更新機制 |

## 五、仍然存在、無法由程式解決的事

- 全實驗室共用一個 token：任一份組員設定檔外流就要全員換新。
- 憑證沒有撤銷機制。
- 使用者自己開啟 `allow_hooks` 後的命令，由使用者自行負責。
- 區網內任何人看得到 mDNS 宣告。
- 工具會改網卡 MAC：使用者必須確保自己有權使用該 MAC，並遵守網路使用規定（見 `SECURITY.md`）。
